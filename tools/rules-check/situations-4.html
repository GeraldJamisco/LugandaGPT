Write Luganda messages

60 situations (set 4): honesty, mixed-language replies, and explaining in Luganda. You write the Luganda, the way people really say it. Nothing you type leaves this computer.

How to use
  1. Each page is one situation in English. Write the Luganda message the way a native speaker would really say it. Do not translate word for word.
  2. The blue box is a guide. For "Honest answer" ones, say you cannot know and (where useful) where to find out - do not guess. For "Reply" ones, answer a real text message the way you would really reply, Luganda mixed with English is fine. For "Explain in Luganda" ones, you MUST answer in Luganda, not English. Never add a time or date the message did not give.
  3. Do not use an AI to write or fix your Luganda. Your own wording is what we need.
  4. If a situation does not make sense or feels unnatural, tick "Skip" and say why in the note.
  5. At the end click Export CSV and Backup JSON, and save both in data\synthetic\ (the file names start with situations4).
