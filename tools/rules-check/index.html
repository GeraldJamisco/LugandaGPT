Luganda time and days: check the rules

We will teach the AI these rules, so they must be exactly right. Nothing you type leaves this computer.

How to use
  1. Each row shows an English time or day and the Luganda I guessed. I am not a native speaker.
  2. If it is exactly right, choose Correct. If not, choose Fix and type the right Luganda in the box.
  3. Empty boxes are things I do not know. Please fill them in.
  4. Where spellings differ (for example Lwokubiri or Lwakubiri), type the one the group agrees is best.
  5. At the end, click Export CSV and Backup JSON, and save both in data\rules\.
