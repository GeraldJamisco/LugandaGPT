Write Luganda messages

60 situations (set 3), aimed at what the blind test showed. You write the Luganda, the way people really say it. Nothing you type leaves this computer.

How to use
  1. Each page is one situation in English. Write the Luganda message the way a native speaker would really say it. Do not translate word for word.
  2. The blue box is a guide. Most situations here give NO time or date, so do not add one. For the "Honest answer" ones, say you cannot know and where to find out. For the mixed-language pairs, first write the request the way people really text it, then on the next page write what was asked for in good Luganda.
  3. Do not use an AI to write or fix your Luganda. Your own wording is what we need.
  4. If a situation does not make sense or feels unnatural, tick "Skip" and say why in the note.
  5. At the end click Export CSV and Backup JSON, and save both in data\synthetic\ (the file names start with situations3).
