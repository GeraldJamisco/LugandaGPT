Benchmark item review

8 draft Luganda test items. Nothing you type leaves this computer.

How to use (4 steps)
  1. Type your reviewer code (for example T1) at the top. Use a code, not your name.
  2. For each item, read the draft. It was written by an AI that is not a native speaker, so do not assume it is right.
  3. Choose Keep, Fix or Drop, then fill in the boxes that appear.
  4. When done, click Export CSV and Backup JSON and save both in data\benchmark\drafts\. Each reviewer should use their own code and their own export.
