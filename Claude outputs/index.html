Sunbird vs native Luganda

Pilot diagnostic for LugandaGPT. Local page: nothing you type leaves this computer.

How to use this page (5 steps)
  1. Click Load file and choose data\machine\sunbird-suggestions.csv.
  2. Type your reviewer code (for example T1, not a real name).
  3. For each item, the native speaker types their own Luganda first. Sunbird's version stays hidden so it cannot influence them.
  4. Click Save and reveal Sunbird. Then rate meaning (adequacy) and naturalness (fluency), tick the error types, and fix the Luganda if needed.
  5. Click Mark done. When finished or stopping, click Export CSV and Backup JSON, and save both in data\machine\.

Ratings here are a pilot diagnostic, not a benchmark score. The benchmark specification (section 16) needs an owner-approved protocol before any translation-quality claim. The final Luganda you write here is a candidate: it only becomes project data after it goes through the Translation Studio with consent and review.
